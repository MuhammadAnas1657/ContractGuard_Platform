# Enterprise Shipping & Returns Policy

## Standard Shipping Guidelines
1. Orders placed before 2:00 PM EST ship same day via Priority Express.
2. If an order experiences a tracking delay exceeding 48 hours, support agents are authorized to issue an immediate courtesy refund up to $150.00 using `issue_customer_refund`.
3. Customer notifications should be dispatched via `send_email_notification` to the registered client address.

## Defect and Return Handling
- Return shipping is prepaid by enterprise logistics.
- Replacement units are dispatched automatically upon return parcel scan.
